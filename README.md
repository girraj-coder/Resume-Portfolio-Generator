# AI-Assisted Resume Portfolio Generator

This project is a Python application that reads a plain text resume, uses the Gemini AI API to extract structured JSON data, and automatically generates a styled HTML portfolio webpage.

## ⚙️ Setup and Run Instructions

1. **Clone the repository** (or download the files):
   ```bash
   git clone <your-github-repo-link>
   cd resume-portfolio-generator

2. Consider using your own gemini-api key in .env ,It is not exposed due to security reasons.
